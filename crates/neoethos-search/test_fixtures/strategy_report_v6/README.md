# Strategy report writer fixture

The JSON pair in this directory is generated by the private Search test
`live_portfolio::tests::regenerate_report_golden_pair_to_temporary_directory`.
Run that exact ignored test explicitly with `--ignored --exact --nocapture`,
review the two printed temporary output paths, then install the reviewed files.
The generator never writes here. Normal tests require the checked-in pair and
compare it byte-for-byte with the current actual Search writers.

The pair uses the existing external `embedded-ctrader-fixture-unverified`
two-column receipt with 80/10/10 scopes, typed selection evidence constructors,
the real research-result constructor and the real compact V6 portfolio writer.
The fixed trade PnLs are synthetic adversarial display data, not executed fills,
and the selection summaries are test fixtures, not financial evidence. The
quality analyzer computes its diagnostics from those PnLs with deterministic
bootstrap and a pinned 21-trading-day convention. Profile timestamps and IDs
are fixed. Each file must remain below 256 KiB.

Only this private synthetic fixture pins its execution metadata to `cpu_only`
and `cpu_scalar`, using the existing validated receipt JSON parser, then rebuilds
all three scopes before constructing artifacts. Source, plan, content and
provenance stay unchanged. This prevents host SIMD detection from changing
golden bytes; it is not evidence that scalar kernels ran. Ordinary runtime
receipts and execution-lane checks are unchanged.

There are two selected genes. `report-selected-a` earns 50 account units from
two trades on its own 1,000-unit initial balance. `report-selected-b` earns 100
from four trades; its normalized report ends at 1,100 with 10% return and 4.55%
drawdown. A nonselected six-trade row earns 26,997 and must never enter the
display. These standalone strategies are not additive portfolio performance.

App tests copy the unchanged pair into an owned temporary research cache and
exercise inventory, selected-member loading, list and detailed report building,
plus adversarial identity/scope/evidence mutations. Passing selection or
calibration remains **unsealed IS diagnostics** in the report; final OOS,
promotion and live authorization flags remain unavailable.

This fixture does not exercise the App's private cost-sidecar publisher, the
complete discovery job, HTTP/UI rendering, independent final evaluation, or
broker execution.
