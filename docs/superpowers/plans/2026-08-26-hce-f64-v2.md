> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every authoritative f64 Half Causal Estimator route use the named NeoEthos UTC-day slot/session proxy, Pine script24 cached-window schedule, and one deterministic stable-f64 numerical authority.

**Architecture:** Keep VectorTA as the sole runtime and the creator source as an audit oracle only. Host routes share chronological Welford population moments, independent estimate/expected-value caches, Pine-style one-pop/one-append maintenance, and a fixed Neumaier dot. Candle routes explicitly map timestamps to UTC-day proxy sessions. Strict CUDA carries one period-invariant time-of-day state in checked global scratch and mirrors the production-default schedule. The public generic CUDA route must either use the same authority or fail closed rather than expose a second same-name result.

**Tech Stack:** Rust f64, CUDA C++ f64, direct `rustc` source/math contracts, remote Cargo/NVCC/RTX gates.
